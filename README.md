# 🚀 Rocket Structure Description

## Multi-Stage Rocket Architecture

### 🔥 First Stage - Booster Section
- **Fuel Type**: Liquid Oxygen (LOX) and Rocket Propellant-1 (RP-1)
- **Engines**: 9 Merlin 1D engines arranged in octaweb configuration
- **Thrust**: 1.7 million pounds of thrust at sea level
- **Purpose**: Provides initial lift-off power and acceleration through dense atmosphere
- **Recovery**: Designed for powered landing and reusability

### ⚡ Second Stage - Upper Stage
- **Fuel Type**: Liquid Oxygen (LOX) and Rocket Propellant-1 (RP-1)
- **Engine**: Single Merlin 1D Vacuum engine optimized for space
- **Thrust**: 220,000 pounds of thrust in vacuum
- **Purpose**: Orbital insertion and payload deployment
- **Features**: Restart capability for multiple orbital maneuvers

### 🛰️ Payload Section
- **Fairing**: Composite structure protecting payload during ascent
- **Capacity**: Up to 22,800 kg to Low Earth Orbit (LEO)
- **Deployment**: Automated payload release mechanisms
- **Configurations**: Supports single or multiple satellite deployments

### 🎯 Navigation & Control Systems
- **Guidance**: Inertial navigation with GPS backup
- **Control**: Grid fins and cold gas thrusters for precision landing
- **Telemetry**: Real-time data transmission to ground control
- **Autonomous**: Self-guided flight termination system for safety

## Launch Sequence
1. **T-10 minutes**: Final systems check and fuel loading complete
2. **T-1 minute**: Flight computer assumes control
3. **T-0**: Engine ignition and liftoff
4. **T+2:30**: First stage separation and second stage ignition
5. **T+8:00**: Payload fairing jettison
6. **T+12:00**: Second stage engine cutoff and payload deployment
